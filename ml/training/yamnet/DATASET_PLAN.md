# 소리 데이터셋 수집·분할 계획

## 목표와 사용 범위

목표 모델의 입력은 16 kHz, mono 오디오이며 출력은 `fire_alarm`, `doorbell`, `other`다. `other`는 배경 소음과 실제 환경의 혼동음을 포함한다. 이 분류기는 기존 화재경보기를 대체하지 않는 보조기기용이다. 데이터셋과 모델 결과만으로 화재 안전 성능을 보증하지 않는다.

초기 단계에서는 공개 데이터로 일반적인 음향 표현과 `other` 범위를 보강하고, 국내에서 직접 수집한 초인종·화재경보음·생활 소음으로 목표 환경을 fine-tuning 및 독립 평가한다. 이번 계획은 **학습 오디오와 데이터셋은 비공개로 보관하고, 모델 가중치만 공개하는 경우**를 기본 시나리오로 둔다. 원본 오디오를 GitHub에 재배포하지 않는다.

비상업적 연구 목적으로 데이터를 비공개 사용한다면, NC 조건 자체는 상업적 이용 제한이므로 그런 사용과 양립할 수 있는 경우가 많다. 다만 `NC`는 데이터 이용허락 중 한 조건일 뿐이며, 출처별 별도 약관·플랫폼 이용조건·개인정보/동의 조건까지 사라지는 것은 아니다. 비공개 프로젝트라도 소스와 개별 파일의 허용 조건을 확인하고 기록한다. 공개 시 저작물 이용에 저작권 허락이 필요한 경우에는 라이선스 조건을 지켜야 하며, 공개 가중치가 원 음원의 각색물/파생물인지 또는 별도 결과물인지는 법률과 구체적 기술·배포 사실에 따라 달라질 수 있다. 따라서 **학습 데이터 비공개만으로 공개 가중치의 권리 상태가 자동으로 해결되지는 않는다.** 불명확한 항목은 권리자 확인 또는 법률 검토 후 공개한다. 이 문서는 법률 자문이 아니다.

## 국내 수집 데이터

### 수집 단위

- 한 샘플은 원본 녹음의 연속된 구간과 그 라벨·환경 메타데이터다. 자른 조각도 같은 `source_recording_id`를 유지한다.
- 한 초인종 이벤트에는 눌림 전의 짧은 환경음, 전체 멜로디/반복, 잔향이 포함되게 녹음한다. 연속 이벤트는 간격이 드러나도록 보존한다.
- 화재경보음은 실제 경보 발생을 유도하지 않는다. 승인된 시험 모드/시험용 발생기/사용 허가된 녹음으로 수집하고, 발생원 유형·패턴을 기록한다. 실제 경보가 울리는 현장에서 수집한 것은 배경 기록으로 분리해 안전한 절차로만 다룬다.
- `other`는 조용한 방만으로 구성하지 않는다. 말소리(내용을 전사하지 않고 음성 존재만 라벨), TV/라디오, 주방·가전, 문·노크, 휴대전화 알림, 사이렌, 기계음, 거리 소음, 무음/저소음 등 모델이 혼동할 가능성이 있는 소리를 포함한다.

### 녹음 조건과 메타데이터

가능한 경우 최종 송신부와 같은 마이크/보드/16 kHz 경로로 녹음한다. 비교를 위해 녹음기 종류와 원본 샘플레이트도 보존한다. 이벤트별로 거리(예: 1/3/5 m), 방향(정면/측면/가림), 방·배치, 배경 소음 수준, 초인종/경보의 기기 유형, 반복 패턴, 녹음 장치와 세션을 기록한다. 모든 파일을 학습 전에 16 kHz mono로 변환하며, 원본을 별도 보관할 때에는 접근 권한을 제한한다.

녹음은 대화 내용을 의도적으로 수집하지 않는다. 음성·TV가 포함될 수 있으면 참여자 동의를 받고 목적·보관 기간·공개 범위를 설명한다. 동의가 없거나 식별 가능한 개인정보가 들어간 녹음은 공개 데이터에 넣지 않는다. 공개에는 동의서 원본/실명/주소를 포함하지 않고, 동의 및 철회 상태만 내부 관리 ID로 추적한다.

## 라벨 기준

- `fire_alarm`: 화재·연기 경보기의 경보 패턴이 분명히 들리는 구간. 발생원과 패턴 유형을 세부 태그로 남긴다.
- `doorbell`: 실제 초인종 이벤트. 집/기기별 개인화 평가에 쓸 수 있도록 안정적인 `household_id`와 `doorbell_id`를 부여한다.
- `other`: 타깃 이벤트가 아닌 모든 소리. 혼동음은 `confuser_tags`로 중복 태깅한다.
- `ambiguous`: 라벨 판단이 불확실하거나 대상 신호가 겹친 구간. 주 분류 학습에서는 제외하고 별도 어려운 사례 평가에 보관한다.
- 타깃과 다른 소리가 겹치면 주 라벨은 타깃으로 하고 겹침을 `overlap=true`로 표시한다. 타깃 발생 전후 구간을 타깃 없는 음성으로 잘못 자르지 않도록 구간 라벨을 확인한다.

파일은 `rec_YYYYMMDD_<random-id>.wav`처럼 의미 없는 ID로 명명한다. 파일명에 사람·주소·집 번호를 넣지 않는다. 녹음별 최소 메타데이터는 `data/metadata/manifest.csv` 열을 따른다.

## 분할 원칙

### 분할 단위와 고정 시험 세트

**파형 조각이 아니라 원본 녹음/발생원/가정 단위로 그룹 분할**한다. 동일 파일의 crop, 증강본, 같은 초인종의 같은 녹음 세션이 서로 다른 분할에 들어가면 안 된다. 같은 초인종이 일반화 학습에 기여한 가정이라면 그 초인종의 모든 파일은 같은 분할에 둔다.

2026-11-08 현재 표본에 적용하는 분할은 **고정 test + 나머지 국내 원본의 4-fold 개발 교차검증**이다. 사용자가 국내 파일의 정답 검수 완료와 서로 다른 발생원임을 확인했다. 알려진 동일 도어락 파일 1개를 제외하고 국내 초인종 20개 중 4개, 화재경보 17개 중 4개, 도어락 6개 중 1개를 test로 고정한다. 나머지 초인종 16개·화재경보 13개·도어락 5개를 4개 개발 fold로 나누어 매 실행마다 3개 fold로 학습하고 1개 fold로 검증한다. 설정 확정 후 국내 개발 원본 전체를 사용한 최종 재학습을 할 수 있다. 이는 현재 표본을 활용하기 위한 시작 설계이며 실험으로 입증한 최적 비율이 아니다. 가정·기기 ID가 없는 현재 test는 발생원 단위 시험이며 미학습 가정 단위 시험으로 부풀려 보고하지 않는다.

ESC-50은 기존 fold 역할을 바탕으로 같은 원본 ID가 여러 분할에 걸치지 않게 합쳐 train 1,200개, validation 398개, test 402개를 유지한다. 해외/국내형 효과음 타깃 3개는 train 전용이다. 정확한 sample ID 목록, 고정 test 잠금 파일과 4개 fold는 [`data/splits/ko-source-cv4-20261108-v1/`](data/splits/ko-source-cv4-20261108-v1/)에 저장한다. 데이터가 추가되면 기존 고정 test를 유지하며 새 버전을 검토한다.

- `train`: 모델 가중치 학습과 데이터 증강에만 사용.
- `validation`: 체크포인트 선택, 임계값·이벤트 후처리 튜닝에만 사용.
- `test`: 모델/임계값 확정 후 최종 1회 평가. test 결과를 보고 재튜닝하면 새 test 세트가 필요하다.
- 별도의 **개인화 시험**에서 각 미학습 가정의 초인종 등록 3회 녹음은 enrollment, 별도 날짜/세션의 추가 녹음은 query로 둔다. 둘 다 해당 가정의 test 그룹 안에 남기며, enrollment 파형·augmentation은 학습에 넣지 않는다. 3회 등록의 충분성은 이 시험 결과로 판단한다.
- 화재경보 미검출 평가는 경보 기기/발생원 단위 홀드아웃 결과를 별도 제시한다. 같은 경보 파일의 인접 crop만 train/test로 나누지 않는다.

분할은 그룹 ID를 기준으로 재현 가능한 스크립트에서 생성하고 seed와 스크립트 버전을 기록한다. 분할을 바꿀 때마다 새 버전으로 기록한다. 원본 녹음, 같은 녹음에서 만든 crop, 파생 특징, 증강본은 모두 원본 그룹의 split을 상속한다.

## 국내 데이터 우선 샘플링

기본 설계는 **클래스 선택 → 원본 그룹 선택 → 해당 그룹의 유효 입력 창 선택** 순서다. 세 클래스는 각 1/3 확률로 선택한다. `fire_alarm`과 `doorbell`에서는 국내 원본 그룹의 추출 가중치를 4, 해외/효과음 보조 그룹은 1로 두고 클래스 내부에서 정규화한다. `other`는 해외 일반 60%, 해외 혼동음 30%, 기존 국내 도어락 10%로 추출하며 각 pool 안에서는 원본 그룹을 균등 선택한다. 창을 미리 전개해 sampler에 넣는 경우 각 창의 확률은 `그룹 선택 확률 / 그 그룹의 유효 창 개수`다. 긴 파일 하나가 학습을 지배하지 않도록 한다.

4배는 시작 후보이며 최적값은 아니다. 같은 fold와 학습 seed에서 1/2/4배를 비교하고, 일관된 개선이 없으면 낮은 가중치를 선택한다. 초기에는 추가 class/domain loss 가중치를 중첩하지 않는다. validation/test는 증강·반복 추출·국내 가중치를 적용하지 않고 전부 평가한다. 설정 및 단계별 상세는 [`config/training_protocol_v1.json`](config/training_protocol_v1.json)과 [`data/splits/README.md`](data/splits/README.md)를 따른다.

일반 `other` 학습은 해외 자료를 주력으로 사용할 수 있다. 다만 국가보다 녹음 장치·거리·방 구조·압축·언어와 TV 내용·생활기기 종류 등 실제 입력 분포를 고려해야 한다. ESC-50 전체는 가정 생활음만 있는 데이터가 아니며, 국내 타깃 대 해외 배경이라는 출처 편향도 생길 수 있다. 모든 국내 생활음을 수집하는 대신 기존 국내 도어락을 유지하고, 실제 송신부로 얻은 소량의 장시간 비타깃 녹음에서 오경보를 점검한다. 이를 보고 튜닝한 녹음은 개발용으로 남기고 별도 녹음을 최종 현장 시험에 쓴다. 선별된 짧은 ESC-50 클립의 오류율을 실제 환경의 시간당 오경보로 대신 보고하지 않는다.

## 평가 지표

전체 accuracy 하나만으로 판단하지 않는다. 클래스별 recall/precision, macro-F1, confusion matrix를 보고하고, 화재경보는 미검출률(경보 이벤트 기준)과 신뢰구간을 우선 표기한다. `other` 장시간 녹음에서 오경보 횟수/시간, 이벤트 감지 지연, 초인종 개인화 전·후 성능을 별도로 측정한다. 가정, 경보 기기, 거리/방향/가림, 배경 소음 수준별 결과와 표본 수를 함께 제시한다.

```text
  processed/           # 원본에서 재생성 가능한 산출물은 필요 시 별도 릴리스
```

기본 보관처는 **비공개 GitHub 저장소**로 한다. 다만 비공개 저장소도 오디오를 GitHub 서버에 업로드하고 저장하는 것이며, 저장소 접근 권한을 받은 협업자도 파일을 볼 수 있다. 그러므로 비공개 설정은 라이선스, 제공처 약관, 참여자 동의, 개인정보 조건을 대체하지 않는다. 해당 조건이 private/third-party cloud storage 및 팀 협업을 허용하는지 확인된 파일만 올린다. 조건이 불분명하거나 로컬 보관만 허용되는 파일은 `data/raw/private/`에 저장하고 Git에 넣지 않는다.

외부 데이터는 가능하면 원 제공처에서 내려받도록 안내하고, 출처·버전·체크섬·라이선스만 registry에 기록한다. 저장소가 private인지 확인하고 접근 권한은 필요한 협업자에게만 부여한다. 큰 파일은 Git LFS 사용을 검토하되, LFS나 private 설정 모두 데이터 이용 허가를 대신하지 않는다. 학습 데이터 자체의 공개는 별도 허가가 없는 한 하지 않는다.

## 실행 순서

1. 후보 원본별 라이선스/이용 조건을 source registry에 기록한다. 내부 비상업 학습 허용 여부, private GitHub/클라우드 저장 허용 여부, 향후 가중치 공개 검토 상태를 별도 관리한다.
2. 녹음 동의 문구, 비식별 ID, 수집 체크리스트를 만든 뒤 국내 데이터 수집을 시작한다.
3. manifest를 채우고 파일 무결성·길이·샘플레이트·클리핑·라벨을 확인한다.
4. 가정/기기/원본 녹음 그룹을 고정한 뒤 train/validation/test split을 생성한다.
5. 클래스 불균형을 기록하고 train에만 증강을 적용한다. validation/test에는 원본 녹음만 둔다.
6. 수집이 늘어도 고정 test는 유지하며, 성능 수치에는 테스트 대상 가정·기기 수를 함께 기록한다.

## 출처 및 확인 링크

- ESC-50 저장소는 전체 데이터에 CC BY-NC를 명시하고, ESC-10 subset은 CC BY라고 구분한다: [공식 README](https://github.com/karolpiczak/ESC-50).
- FSD50K는 개별 Freesound 클립마다 CC 라이선스가 다르며 dataset 전체의 attribution 조건도 별도다: [FSD50K companion site](https://fsannotator.upf.edu/fsd/release/FSD50K/), [Zenodo 배포](https://zenodo.org/records/4060432). 다운로드한 배포본의 클립별 license mapping을 보존한다.
- AudioSet은 오디오 파일 대신 YouTube segment 목록/특징 등을 제공하고, 영상 원본은 해당 CC 라이선스와 별개다: [Google AudioSet 다운로드 안내](https://research.google.com/audioset/download.html).
- AI-Hub는 데이터별 이용 조건 확인이 필요하다: [AI-Hub 소개](https://www.aihub.or.kr/intrcn/intrcn.do?currMenu=150&topMenu=105).
