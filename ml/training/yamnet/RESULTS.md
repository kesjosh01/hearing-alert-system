# 2026-11-09 기준 모델 학습 상태

`first_fold0_w4`는 국내 타깃 가중치 4배를 사용한 첫 fold의 개발 실험입니다. 16 epoch를 실행했고, 검증 기준으로 8 epoch의 체크포인트를 선택했습니다.

| fold 0 검증 지표 | 결과 |
| --- | ---: |
| 국내 원본 그룹 정확도 | 9/10 (90.0%) |
| 국내 화재경보 그룹 recall | 4/4 (100%) |
| 국내 초인종 그룹 recall | 3/4 (75.0%) |
| 국내 타깃 두 클래스 그룹 recall 평균 | 87.5% |
| 전체 원본 그룹 macro-F1 | 0.821 |
| 해외 other 클립의 타깃 오탐 | 10/398 (2.51%) |
| 국내 도어락 그룹의 타깃 오탐 | 0/2 |

`integration_cv_1epoch`와 `integration_refit_1epoch`는 4-fold, OOF 집계와 재학습 경로를 확인한 실행입니다. CV 네 fold 모두 검증 가드 기준을 통과하지 못했습니다. `smoke` 계열 실행은 특징 추출과 저장·재로딩 점검에 사용했습니다.

고정 test는 평가하지 않았습니다. 위 수치는 파일·원본 그룹 기준입니다. 실제 경보 이벤트 미검출, 시간당 오경보, ESP32-S3 추론 성능은 이후에 측정해야 합니다.
