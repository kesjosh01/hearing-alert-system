성능 해석

기존 test의 정분류는 화재경보 2/4, 초인종 2/4입니다. 학습·변환 완료와 실사용 감지 성능을 구분하며, 보드 배포 준비 완료로 판단하지 않습니다. 전체 411개 중 403개가 other이므로 전체 정확도만으로 감지 품질을 판단하지 않습니다.

파일 라벨 학습

각 파일의 모든 1초 창 확률을 평균한 뒤 파일 정답으로 손실을 계산했습니다. 1초 창별 정답이나 이벤트 시간 구간을 만들어내지 않았습니다. 원본 그룹·클래스·other pool 확률을 유지하고 그룹 안에서 파일을 균등 선택했습니다. 긴 파일은 손실에서 파일 하나의 비중을 갖습니다. BN 통계는 각 microbatch 안의 창 분포에 영향을 받습니다.

타깃 판정 임계값은 개발 OOF·기존 해외 validation에서 선택하고 refit과 test 전에 고정합니다. 원시 확률은 유지하며 선택 임계값에 못 미친 타깃을 other로 판정합니다. 기존 YAMNet과 학습 감독·예산 및 신규 초인종 5개 포함 여부가 다르므로 모델 구조만의 통제 비교가 아닙니다. 보드·실시간 마이크 검증은 별도입니다.
