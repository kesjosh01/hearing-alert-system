# 첫 모델 비교·고정 평가와 현재 데이터 보강 상태

현재 제품 목표는 **미달·미검증**입니다. 마이크와 알림 장치가 없고 실제 기기 사용 기간은 0일입니다. 첫 비교 연구의 학습·정수화·고정 공개 평가를 마쳤지만, 이를 화재경보 99.9%, 초인종 95%, 30일당 오알림 1회 이하의 근거로 바꿔 말할 수 없습니다. 추가 목표 음원과 새로운 검증 자료의 보강은 계속 진행합니다.

실제 optimizer step이 기록된 학습 실험은 29개입니다. 이전 데이터·모델 등 보호 대상 573개 파일은 해시가 모두 일치합니다.

## 학습과 분리한 최종 공개 녹음 평가

모델·출력 임계값·원본 식별자·평가 코드를 먼저 고정한 뒤 1,959개 녹음을 평가했습니다. 화재경보 47개, 초인종 118개, 일반 소리 1,794개입니다. 새 국내 양성 녹음은 없습니다. 파일 안에서 한 번이라도 감지했는지를 센 결과이며 실제 발생 사건의 감지율과 다릅니다.

확인된 해외 도어벨·화재경보·사이렌은 정답 양성입니다. 다른 목표 클래스로 잘못 감지한 경우는 별도 기록했습니다. 일반 소리 파일의 오감지 비율은 기기당 오알림 횟수나 30일 오알림률이 아닙니다. 알려진 녹음·발생원 그룹·제작자 ID·동일 PCM이 개발 자료와 겹치지 않는지 검사했지만, 모든 물리 기기 ID와 YAMNet 사전학습 자료 노출까지 보장하지는 않습니다.

후보 전체의 오감지 합집합 25개 녹음에 대해 공개 라벨·제목·태그·설명을 확인했습니다. 해당 메타데이터에서 실제 도어벨·화재경보라고 확인된 파일은 없었습니다. 주요 예시는 교회 종·풍경·시계·악기·교통·가정 소리입니다. 새 청취 검수로 확정한 결과는 아니며, 모델이 틀렸다는 이유로 라벨이나 분모를 바꾸지 않았습니다. 근거는 `final_public_other_error_metadata.json`에 있습니다.

RealDESED의 초인종 음향 구간 104개도 별도로 평가했습니다. 이는 버튼 누름 횟수 주석이 아닙니다. 아래는 구간 시작부터 종료 1초 후까지 양성 창의 끝점이 한 번 이상 있었는지 센 진단입니다.

## 국내 음원 특화와 합성 조건 시험

국내 원음은 화재경보 17개, 초인종 26개이며 모두 학습에 사용했습니다. 원음 43/43 감지를 달성한 작은 int8 후보를 보존했습니다. 변형 음원은 새로운 독립 기기나 새 원음으로 세지 않았습니다.

학습 원음과 배경음을 새로 조합한 별도 합성 시험 결과입니다. 각 모델과 임계값을 고정한 뒤 비교했습니다. SNR은 전체 파일 RMS 기준이며 실제 방이나 마이크를 재현했다고 주장하지 않습니다.

| 후보 | −18 dB: 화재/초인종 | 새 잔향·SNR 15 dB: 화재/초인종 | 새 잔향·SNR 5 dB: 화재/초인종 |
|---|---:|---:|---:|
| domestic_known_v1 | 13/17 · 22/26 | 16/17 · 22/26 | 13/17 · 14/26 |
| domestic_known_aug_v2 | 16/17 · 23/26 | 17/17 · 21/26 | 14/17 · 13/26 |
| domestic_known_enriched_v3 | 8/17 · 14/26 | 14/17 · 16/26 | 11/17 · 6/26 |

잡음 증강이 일부 화재 조건에서는 개선됐지만 초인종은 일관되게 좋아지지 않았습니다. 더 많은 일반 소리를 넣은 최신 모델도 기존 후보를 전반적으로 넘지 못했습니다. epoch 증가만으로 해결됐다는 증거가 없어 조기 종료와 선택된 최적 epoch를 유지했고, 마지막 epoch를 자동 채택하지 않았습니다.

YAMNet teacher를 사용한 KL distillation은 실제 학습으로 수행했습니다. 이 비교에서는 작은 모델 기준선을 개선하지 못했습니다. 국내 특화 후보에는 KD를 쓰지 않았고, 일반 64-bin 후보는 YAMNet 앞부분의 사전학습 가중치 전이를 사용했습니다. 가중치 전이와 distillation은 서로 다른 실험입니다.

## 제품 목표를 입증하려면

| 사용자 목표 | 현재 확보한 실제 제품 근거 | 추가로 필요한 근거 |
|---|---|---|
| 실제 화재경보 발생의 99.9% 이상 | 없음 | 대표 환경의 실제 경보 발생 시각과 감지 로그 |
| 실제 초인종 발생의 95% 이상 | 없음 | 독립된 실제 초인종 누름 시각과 감지 로그 |
| 기기당 30일 오알림 1회 이하 | 실제 기기 0일 | 고정된 최종 모델·마이크·알림 제어기의 실제 장기 기록 |

이상적인 독립 표본에서 실패가 0회라고 가정해도, 각 지표별 단측 95% 근거에는 화재 2,995회, 초인종 59회가 최소로 필요합니다. 동질 Poisson 가정으로 오알림이 0회인 경우에도 약 89.9 기기·일이 필요합니다. 이는 사용자 목표에 대한 계산 예시이며 인증 규정이나 세 지표의 동시 95% 보장은 아닙니다. 같은 파일 재생·합성 변형·학습 파일 개수는 독립된 실제 발생 횟수로 대체할 수 없습니다. 계산 근거는 [NIST 정확 이항 신뢰한계](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbici.htm)와 [NIST 일정 사건율·0회 관측 신뢰한계](https://www.itl.nist.gov/div898/handbook/apr/section4/apr451.htm)입니다.

## 수집·산출물 범위

공개 음원은 기존 환경으로 수집했고 원본·라이선스·원격 버전·해시를 기록했습니다. 수집한 모든 파일을 모든 모델에 넣은 것은 아닙니다. 고정 데이터셋 밖에 있는 추가 파일은 후속 작업용으로 보존했습니다.

- FSD50K_targets: {'verified_shards': 3, 'verified_files': 270, 'planned_files': 270, 'full_queue_complete': True}
- FSD50K_hard_negatives: {'verified_shards': 25, 'verified_files': 3166, 'planned_files': 3166, 'full_queue_complete': True}
- FSD50K_background: {'verified_shards': 184, 'verified_files': 23545, 'planned_files': 23545, 'full_queue_complete': True}
- FSD50K_noncommercial_research_targets: 30
- RealDESED_official_native_recordings: 5711
- FLEURS_ko_native_recordings: 2915
- AudioSet_strong_training_targets_retained: 803
- AudioSet_train_source_shards_scanned: 881
- Synthetic_smoke_procedural_files_not_independent_devices: 250

AudioSet strong 전체 3,405개 train shard 중 881개를 조사했습니다. FSD50K background 수집은 용량 여유 조건을 따르며, 전체 인터넷 자료를 수집했다고 주장하지 않습니다. RealDESED 우선 수집본·미러·전체 원본은 같은 녹음을 중복 개수로 세지 않았습니다. 비상업 라이선스 자료와 원본별 이용 조건이 남아 있어 상용 제품 사용권은 별도 확인이 필요합니다.

후보 폴더의 `.tflite`, C++ 헤더, 출력 계약과 해시를 보존했습니다. 작은 국내 후보는 기존 98×40 frontend 계약을 따릅니다. 일반 후보는 96×64 frontend를 요구하여 기존 펌웨어에 바로 넣을 수 없습니다. 보드 RAM·지연·전력·마이크 응답·진동/LED 전달·중복 알림 억제는 실제 장치에서 확인하지 않았습니다.

첫 고정 공개 평가의 음원·모델·임계값·결과는 보존합니다. 다음 연구에서는 새 자료의 분할과 중복 검사를 먼저 고정하며, 기존 평가를 다시 미관측 시험이라고 부르지 않습니다. 목표 달성 여부는 false로 유지합니다. 다음 제품 검증에는 실제 마이크·알림 장치와 독립된 국내 동작 기록이 필요합니다.

## 다음 개선의 우선순위

1. 실제 사용할 마이크로 국내 경보·초인종의 새 기기·거리·방·배경 조건을 확보하고, 개발 자료와 최종 시험 자료를 발생원 단위로 분리합니다.
2. 새 수집에서는 실제 경보 시작·버튼 누름 시각을 함께 기록합니다. 기존 파일 라벨 학습은 유효하지만 파일 감지와 사건 감지의 차이를 해결하지는 못합니다.
3. 실제 장기 배경음과 알림 로그로 임계값·중복 알림 제어를 검증합니다. 현재의 선택 자료 오감지 0 조건을 월간 신뢰도로 간주하지 않습니다.
4. 그 새 개발 자료에서 증강·가중치·모델 용량을 다시 비교합니다. 이번 최종 공개 시험으로 재튜닝하거나 epoch만 늘려 성공을 주장하지 않습니다.
