학습 방식과 해석

이전에는 distillation이 없었습니다. 이번에는 각 fold 검증 그룹을 학습하지 않은 YAMNet teacher의 정렬 logits을 사용해 실제 KL 손실로 student를 학습합니다. 시간 구간 검수로 기록하지 않습니다.

정답 파일 CE 0.5 + T² KL 0.5, T=2입니다. 주파수 정보 보존·가벼운 SpecAugment·채널 수를 단계적으로 비교합니다. 모든 선택은 개발 자료로 수행하며 기존 test는 독립 시험이 아닙니다.

고정 모델의 기존 test 회고적 비교

기존 test int8 기준 재현율은 50.00% → 62.50%로 높아졌지만, 해외 비목표 소리 오탐은 3/394 → 24/394 (6.09%)로 늘었다. 개발 fold의 가드는 통과했지만 기존 test의 오탐률은 5%보다 높다. 모든 감지 지표가 개선됐다고 볼 수 없으며 실사용 교체·배포를 권장하지 않는다. 결과는 개선 실험 모델로 보존한다.

사용자 요청으로 해외 siren을 비목표 소리의 오탐 평가에서 제외했다. test의 8개, validation의 8개 전체를 예측과 무관하게 분자·분모에서 제외하며 모델·임계값은 변경하지 않았다. 원래 평가 JSON과 모델 묶음은 보존했다. 추가 데이터·epoch 판단과 평가 수정
