# 추가 데이터·epoch 판단과 해외 other 오탐 평가 수정

2026-11-14 사용자 요청에 따라 기존 학습·예측 기록을 분석했다. 추가 학습, 데이터 수집, 모델 추론, 임계값 재보정은 실행하지 않았다. 원본 음원·라벨·분할·모델·원래 평가 JSON은 보존했다.

## 1. 추가 데이터 판단

**일반화 성능을 더 높이려면 서로 다른 발생원의 추가 데이터를 권장한다. 단순한 epoch 증가보다 우선순위가 높다.** 현재 데이터로 학습과 모델 변환은 완료했지만, 다음 자료만으로 새로운 가정·기기의 감지 성능을 충분히 입증하기는 어렵다.

| 국내 개발 OOF 자료 | 독립 source group 수 | 올바르게 분류한 group |
|---|---:|---:|
| 화재경보 | 13 | 9 |
| 도어벨 | 21 | 16 |
| 도어락(other) | 5 | 5 |

이는 선택 모델 `kd24_freq_aug`의 개발 예측이다. 개발 평균 타깃 recall 73.13%는 fold별 macro recall을 평균한 값이다. 위 support로 전체 정답 수를 나눈 값과 계산 방식이 다르다. 모델·임계값 선택에도 사용했으므로 독립 시험 성능으로 해석하지 않는다.

개발 음원은 해외 배경음 등을 합쳐 1,640개·1초 창 15,502개지만, 같은 원음에서 자른 창이 새로운 기기·가정을 추가해 주지는 않는다. 현재 해외 보조 타깃도 train-only 화재경보 1개·도어벨 2개뿐이다. 기존 국내 test의 타깃은 각 클래스 4개여서, 한 파일의 정오분류가 해당 클래스 recall을 25%p 바꾼다.

다음 데이터의 우선순위는 다음과 같다. 이 목록은 수집을 실행하거나 특정 수량의 성능 향상을 보장한다는 뜻이 아니다.

1. **라벨 기준 정리:** ESC-50 `siren`은 기존 train 24개, validation 8개, test 8개가 모두 `other`다. 사용자가 해외 사이렌도 목표와 유사하다고 정한 현재 기준과 학습의 비목표 라벨이 충돌할 수 있다. 다음 학습 전에는 사이렌을 세부 청취해 목표 클래스에 맞게 분류하거나, 세부 종류가 불명확한 음원을 비목표 학습 자료에서 제외할지 정해야 한다. 모든 사이렌을 화재경보 정답으로 자동 변경하지 않는다.
2. **양성 다양성:** 국내 화재경보를 우선하고, 다른 초인종 기기·가정·거리·방향·문 닫힘·음량·잡음 조건을 추가한다. 해외 음원도 실제 도어벨·화재경보임이 확인되면 양성 자료 후보가 된다. 국적만으로 `other`로 정하지 않는다.
3. **비목표 소리:** 생활·환경 배경음, 도어락 등 현장 녹음을 추가한다. 기존 회고적 오탐에는 귀뚜라미·벌레·동물·아기 울음·진공청소기·교회 종 등이 남아 있다. 이는 다음 자료 구성의 참고이며, 현재 고정 모델을 이 test에 다시 맞추지는 않았다.
4. **분할:** 같은 기기·원음·녹음 세션의 재생·편집·잘라낸 버전을 학습과 평가에 나누지 않는다. 다음 개선의 검증용으로 새로운 발생원의 평가 자료도 따로 확보한다.

현재 결과만으로 필요한 최소 추가 파일 수를 산출할 수는 없다. 같은 파일 복제나 무음 창의 증가는 우선 해법이 아니다. 사용자가 직접 청취한 파일 라벨은 계속 사용할 수 있으며, 이번 판단을 위해 시간 구간 검수를 필수로 되돌리지 않는다.

## 2. epoch 증가 판단

**현재 선택 모델의 epoch을 단순히 늘리는 것은 권장하지 않는다.** 개발 학습의 한도는 30 epoch, patience는 8이며 네 fold 모두 한도 전에 조기 종료됐다.

| fold | 최적 checkpoint epoch | 실제 종료 epoch | 파일 라벨 학습 손실: 최적 → 마지막 | epoch별 개발 타깃 recall: 최적 → 마지막 |
|---|---:|---:|---:|---:|
| 0 | 4 | 12 | 0.2977 → 0.2074 | 62.50% → 33.33% |
| 1 | 7 | 15 | 0.2390 → 0.1819 | 80.00% → 63.33% |
| 2 | 11 | 19 | 0.2266 → 0.1973 | 83.33% → 66.67% |
| 3 | 17 | 25 | 0.1771 → 0.1622 | 66.67% → 50.00% |

각 epoch의 recall은 그 epoch에서 개발 자료로 선택한 임계값에 따른다. 고정 임계값에서 epoch만 바꾼 인과 비교는 아니지만, 학습 손실 감소와 검증 성능 저하가 함께 나타나 추가 반복만으로 개선될 근거가 약하다. 30을 60으로 올려도 같은 조기 종료 조건이면 현재 종료 시점은 바뀌지 않는다. patience까지 늘리는 것은 과적합 위험을 키울 수 있다.

최종 전체 개발 refit의 **9 epoch은 네 최적 epoch [4, 7, 11, 17]의 중앙값**으로 사전에 고정했다. 9회에서 임의로 중단한 학습이 아니다. 다른 후보 `kd24_freq`의 한 fold는 30회 한도에 도달했으나 최적 checkpoint는 25회였고, 선택 모델에서 학습 부족을 보인 근거는 아니다. 다음 실험은 라벨·발생원 다양성을 정리한 뒤 별도 개발 자료로 학습률·학습량을 비교하는 것이 적절하다.

조기 종료의 일반적인 patience 의미는 [Keras 공식 EarlyStopping 문서](https://keras.io/api/callbacks/early_stopping/)와 같다. 이 프로젝트는 자체 학습 루프에서 복합 개발 순위를 감시하며, Keras의 기본 `val_loss` callback을 사용했다는 뜻은 아니다.

## 3. 해외 목표 유사 음원의 오탐률 제외 적용

기존 해외 other 평가 음원은 ESC-50이다. 원본 메타데이터의 50개 분류에는 별도 `doorbell`·`fire_alarm` 항목이 없으며, `siren` 분류가 확인됐다. 파일 안의 모든 소리를 새로 청취해 조사한 결과라는 뜻은 아니다. 사용자 기준에 따라 **`siren` 분류 전체를 비목표 소리 평가 모집단에서 제외**했다. 일부 오탐 파일만 골라 제외하지 않았다. `clock_alarm`·`church_bells`·문 두드림은 도어벨·화재경보로 확인되지 않아 그대로 남겼다.

| 고정 모델 | 원래 해외 other 오탐 | 사이렌 8개 제외 후 오탐 |
|---|---:|---:|
| 초기 baseline float | 6/402 = 1.49% | **3/394 = 0.76%** |
| 초기 baseline int8 | 6/402 = 1.49% | **3/394 = 0.76%** |
| 개선 모델 float | 29/402 = 7.21% | **26/394 = 6.60%** |
| 개선 모델 int8 | 27/402 = 6.72% | **24/394 = 6.09%** |

분자에서는 각 모델의 사이렌 오탐 3개를, 분모에서는 판정과 무관하게 사이렌 8개 전체를 제외했다. **현재 보고할 해외 비목표 소리 오탐률은 오른쪽 열이다.** 정의 수정에 따른 수치 변화이며 모델 자체의 개선이 아니다. 국내 타깃 recall은 기존 모델 50.00%, 개선 모델 62.50%로 그대로다. 개선 int8 모델은 이 기준에서도 해외 오탐률 5%를 넘어 실사용 교체·배포를 권장하지 않는다.

기존 validation도 동일하게 사이렌 8개를 제외한 390개로 재계산했다. 모델·checkpoint·임계값은 원래 선택 그대로다.

| 선택 모델의 고정 개발 정책 | 수정된 해외 비목표 소리 오탐 |
|---|---:|
| fold 0 | 6/390 = 1.54% |
| fold 1 | 16/390 = 4.10% |
| fold 2 | 8/390 = 2.05% |
| fold 3 | 7/390 = 1.79% |
| 9 epoch refit validation | 9/390 = 2.31% |

validation 모집단은 fold 간 재사용한 동일 자료다. 네 fold를 합쳐 새로운 1,560개 음원인 것처럼 계산하지 않는다. 학습 당시 원래 가드도 통과했고 이번 평가 기준에서도 위 개발 수치는 5% 이하다. 기존 test의 초과와 구분한다. 과거에 관측한 test를 재계산한 결과여서 새로운 독립 시험은 아니다. 사이렌 세부 정답을 추정해 양성 recall이나 전체 F1을 새로 계산하지도 않았다.

## 저장한 근거와 재현

- [policy.json](policy.json): 예측과 무관한 제외 기준. 미래 평가에도 동일한 발생원 분류 기준을 적용한다. 기존 frozen 학습 코드는 과거 재현을 위해 보존했다.
- [results.json](results.json), [metrics.csv](metrics.csv): 기존 저장 예측의 45개 고정 정책 평가. 원래 FPR을 먼저 재현한 후 모집단을 수정했다.
- [excluded_predictions.csv](excluded_predictions.csv): 모델별 제외 음원 ID·원래 라벨·판정·분류와 사유.
- [source_category_inventory.csv](source_category_inventory.csv): 50개 원본 분류의 train/validation/test 개수.
- [data_and_epoch_evidence.json](data_and_epoch_evidence.json): 국내 발생원 수, epoch별 근거, 학습 자료에 남아 있는 사이렌 수.
- [verification.json](verification.json): 입력·모델 묶음·원래 평가의 SHA-256 보존과 추가 학습/추론 0회 확인.

재계산 도구는 [recompute_negative_fpr.py](../../../tools/recompute_negative_fpr.py)다. 기존 출력에 덮어쓰지 않는다. 같은 프로젝트의 기존 Python 환경에서 새로운 출력 폴더를 지정하면 실행할 수 있다. 이 도구는 ML runtime을 불러오지 않고 CSV·JSON만 읽는다.

배포 묶음 내부의 원래 지표와 `FINAL_VERIFICATION.json`은 당시 실험의 기록이다. 모델 묶음 해시를 유지하고 이 보고서·정책·결과를 최신 평가 정의의 별도 수정 기록으로 둔다.
