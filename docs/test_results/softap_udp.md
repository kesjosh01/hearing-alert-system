# SoftAP UDP 검증 기록

날짜: 2026-10-29. 대상: LILYGO T7 S3 v1.1 / ESP32-C3 SuperMini.

## PC 검증

- 환경: Ubuntu, 로컬 ESP-IDF v5.5.5, GCC 14.2.0.
- ESP32-S3: 컴파일·링크·바이너리 생성 및 파티션 크기 검사 통과.
- ESP32-C3: 컴파일·링크·바이너리 생성 및 파티션 크기 검사 통과.
- 빌드 크기: S3 `0xa6f70`, C3 `0xb0d60` 바이트. 두 타깃 모두 1MB 앱 파티션 이내. 빌드 로그에서 컴파일 경고·오류가 발견되지 않았습니다.
- 코드 검토: 고정 길이·버전·종류·발신 주소 검사, big-endian 직렬화, 세션·순번 기반 ACK 매칭, 최대 4회 재전송, 중복/과거 순번 처리 억제, 수신부 재등록·만료 경로 확인.
- 이 단계는 크로스 컴파일 및 코드 검토이며, 보드 실행·패킷 손실 주입 테스트를 수행했다는 의미가 아닙니다.

## 실물 검증 (미수행)

작성 시점에 `/dev/ttyACM*`, `/dev/ttyUSB*` 장치를 발견하지 못했습니다. 플래시와 실제 무선 통신은 실행하지 않았습니다. 다음 표는 측정 후 채웁니다.

| 실험 | 확인할 내용 | 결과 |
| --- | --- | --- |
| 첫 연결 | DHCP → HELLO → TEST → ACK | 미측정 |
| 100개 이벤트 | 고유 수신 수, ACK 수, 실패 수, 재시도 수 | 미측정 |
| 확인 지연 | 단일 시도 ACK elapsed 최소/평균/최대 | 미측정 |
| C3 전원 재인가 | heartbeat 만료, 새 세션 등록, 수신 재개 | 미측정 |
| S3 전원 재인가 | C3 자동 재접속, 새 S3 세션 처리 | 미측정 |
| ACK 억제 | 4회 시도 후 FAILED, C3 중복 처리 억제 | 미측정 |
| 거리·장애물 | 조건별 실패율·확인 지연 | 미측정 |

테스트 시 전원, 보드 실크/리비전, USB 포트, 거리, 장애물, 펌웨어 변경 사항, 전체 송수신 로그를 함께 기록합니다. ACK 지연은 편도 전송 지연이 아닙니다. 실행 방법은 [실험 README](../../communication_tests/softap_udp/README.md)를 따릅니다.
